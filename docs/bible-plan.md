# CrossPoint Bible 계획

CrossPoint 한국어 펌웨어(`release/korean`, 1.6.5-ko.1)를 성경 전용 펌웨어로 줄인다. 성경 본문은 펌웨어에 넣지 않는다. 사용자가 가진 EPUB을 PC에서 성경 팩(`.cpb`)으로 바꿔 SD에 넣는다.

## 목표

- 책 → 장 → 절로 몇 번의 버튼 입력만에 이동한다. 책은 목록에서 고르고, 장과 절은 숫자로 고른다.
- 큰 글씨. 본문 글꼴 크기를 여러 단계로 내장한다.
- 쓰지 않는 기능(네트워크, OTA, OPDS, KOReader 동기화, 라이브러리, EPUB/XTC/TXT 리더, 사전, 이미지 뷰어)은 뺀다.
- UI 문자열은 I18n(`lib/I18n`)으로 유지해 나중에 다른 언어를 붙일 수 있게 한다. 책 이름은 팩에서 읽는다.

## 저작권

개역개정은 대한성서공회 저작물이다. 저장소와 펌웨어 이미지에 본문을 넣지 않는다. 팩은 `tools/bible/epub2cpb.py`로 사용자가 만들고, 에뮬레이터 테스트도 로컬 EPUB에서 그때그때 만든다(`sim/out`, gitignore).

## 데이터: 성경 팩 `.cpb`

형식은 `docs/bible-pack-format.md`. 요점:

- 헤더 64바이트, 책 표(66 × 64B), 장 표(1,189 × 8B), 절 오프셋 표(u32), 절 플래그(문단 시작, 시 행), 소제목 표, UTF-8 본문.
- (책, 장, 절) → 본문 위치가 표 두 번 읽기로 끝난다. HTML 파싱이 기기에 없다.
- 2018 개역개정 EPUB: 31,102절, 소제목 2,420개, 4.8MB. 한글은 1,234자이고 전부 KS X 1001 안에 있다.

## 단계

1. **팩 변환기** `tools/bible/epub2cpb.py`와 형식 문서. 호스트 테스트로 표본 절을 대조한다.
2. **팩 리더** `lib/BiblePack`: 헤더 검증, 책/장/절 조회, 절 본문 읽기. 호스트 gtest.
3. **성경 화면** (`src/activities/bible/`)
   - `BibleReaderActivity`: 장 단위로 절을 이어 그린다. 절 번호, 소제목, 시편 표제를 표시한다. 좌우 버튼으로 쪽, 장 끝에서 다음 장으로 넘어간다. 마지막 위치를 저장한다.
   - `BookSelectActivity`: 구약/신약 탭과 책 격자.
   - `NumberSelectActivity`: 장, 절 번호 고르기(격자, 위아래 10씩 이동).
   - 리더 메뉴: 장절 이동, 글꼴 크기, 줄 간격, 화면 방향.
4. **홈 대체**: 부팅하면 마지막 읽던 곳으로 간다. 홈은 "이어 읽기 / 책 고르기 / 설정"만 둔다.
5. **글꼴**: KoPub Batang을 KS X 1001 한글로 줄이고 압축해 여러 크기로 내장한다(한자 제외). UI 글꼴도 한 단계 키운다.
6. **기능 제거**: 네트워크(Wi-Fi, 웹 서버, OTA, wolfSSL), OPDS, KOReader, 라이브러리, EPUB/XTC/TXT, 사전, 이미지 뷰어와 관련 lib, 테스트를 지운다. SD 펌웨어 업데이트는 남긴다(유일한 갱신 경로).
7. **이름**: CrossPoint Bible, 버전 `0.1.0`. 부팅 화면과 About.
8. **에뮬레이터 시나리오** `sim/`: 팩을 넣은 SD로 부팅 → 책 고르기 → 장/절 이동 → 쪽 넘김 → 글꼴 크기 변경을 찍어 golden과 비교한다.

## 뒤로 미룬 것

- 본문 검색(한글 입력기 필요). 팩에 색인을 덧붙이는 방식으로 형식 버전 2에서 한다.
- 북마크, 형광펜, 여러 번역 대조.
- X4(800×480) 화면 배치는 에뮬레이터가 지원하지 않아 실기기로 확인한다.
