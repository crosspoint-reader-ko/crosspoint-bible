# 성경 팩 형식 (`.cpb`)

CrossPoint Bible이 읽는 성경 데이터 파일이다. `tools/bible/epub2cpb.py`가 만들고 `lib/BiblePack/BiblePack.cpp`가 읽는다. 기기는 HTML을 파싱하지 않고, 표 두 번을 읽어 (책, 장, 절)의 본문 위치를 찾는다.

## 만들기

```sh
python3 tools/bible/epub2cpb.py "성경전서 개역개정판.epub" krv.cpb --title 개역개정
```

SD 카드의 `/bible/` 폴더에 넣는다. `.cpb`가 여러 개면 이름순 첫 파일을 연다.

- 지원하는 EPUB: "ESV 템플릿" 한국어 성경(`bNN.MM.Name.text.html`, `span.chapter-num`, `span.verse-num`, `p.heading`).
- `--charset FILE`은 본문에 쓰인 글자를 모두 적는다. 글꼴 범위를 확인할 때 쓴다.
- 변환할 때 원본의 오타 몇 가지를 고친다(`FIXUPS`: 떠도는 `^`, `{}`, `ㅘㅇ하` → `왕하`).

## 구조

모든 정수는 리틀 엔디언이다. 각 구역은 4바이트 경계에 맞춘다.

### 헤더 (64바이트)

| 오프셋 | 형식 | 내용 |
|---|---|---|
| 0 | `char[8]` | `CPBIBLE\0` |
| 8 | u16 | 형식 버전 (1) |
| 10 | u16 | 책 수 (66) |
| 12 | u32 | 장 수 |
| 16 | u32 | 절 수 |
| 20 | u32 | 제목 오프셋 (UTF-8, NUL 종료, 최대 64바이트) |
| 24 | u32 | 책 표 오프셋 |
| 28 | u32 | 장 표 오프셋 |
| 32 | u32 | 절 오프셋 표 오프셋 |
| 36 | u32 | 절 플래그 표 오프셋 |
| 40 | u32 | 소제목 표 오프셋 |
| 44 | u32 | 소제목 수 |
| 48 | u32 | 본문 오프셋 |
| 52 | u32 | 본문 크기 |
| 56 | `char[8]` | 언어 코드 (`ko`) |

### 책 표 (책마다 64바이트)

| 오프셋 | 형식 | 내용 |
|---|---|---|
| 0 | u8 | 0 = 구약, 1 = 신약 |
| 1 | u8 | 정경 번호 1..66 |
| 2 | u16 | 장 수 |
| 4 | u32 | 첫 장의 장 표 인덱스 |
| 8 | `char[40]` | 이름 (`요한복음`) |
| 48 | `char[16]` | 약어 (`요`) |

### 장 표 (장마다 8바이트)

u32 첫 절의 전체 절 인덱스, u16 절 수, u16 첫 소제목 인덱스(이 장의 첫 절 이상을 가리키는 첫 소제목).

### 절 오프셋 표

u32 × (절 수 + 1). 절 `i`의 본문은 본문 구역의 `[off[i], off[i+1])`이다.

### 절 플래그 표

절마다 u8. bit 0 = 문단이 시작하는 절, bit 1 = 시 행(`p.line`).

### 소제목 표 (12바이트)

u32 절 인덱스(소제목이 이 절 바로 위에 온다), u32 본문 구역 안의 오프셋, u16 길이, u8 종류(0 소제목, 1 시편 표제, 2 시편 권 구분), u8 0. 절 인덱스 순으로 정렬한다.

### 본문

절 본문을 차례로 이어 붙이고, 그 뒤에 소제목 본문을 붙인다. 구분자는 없다.

## 크기

2018 개역개정 EPUB(5.9MB) → 4.8MB, 31,102절, 1,189장, 소제목 2,420개.

## 버전을 올릴 때

헤더의 버전을 올리고 `BiblePack::FORMAT_VERSION`과 함께 바꾼다. 기기는 모르는 버전의 팩을 열지 않는다. 본문 검색 색인은 버전 2에서 구역을 덧붙이는 방식으로 넣는다.
