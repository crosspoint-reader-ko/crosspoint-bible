# 성경 팩 형식 (`.cpb`)

CrossPoint Bible이 읽는 성경 데이터 파일이다. `tools/bible/epub2cpb.py`가 만들고 `lib/BiblePack/BiblePack.cpp`가 읽는다. 기기는 HTML을 파싱하지 않는다. 표를 읽어 (책, 장, 절)이 든 장을 찾고, 그 장의 압축 블록 하나만 푼다.

지금 형식은 버전 2다. 장마다 raw deflate 블록 하나로 본문을 압축한다(글꼴과 같은 방식, 기기에서는 `InflateReader`/uzlib로 푼다).

## 만들기

```sh
python3 tools/bible/epub2cpb.py "성경전서 개역개정판.epub" krv.cpb --title 개역개정
```

두 가지로 쓸 수 있다.

- **펌웨어에 내장**: 빌드할 때 `scripts/embed_bible_pack.py`가 EPUB(`$BIBLE_EPUB`, `custom_bible_epub`, iCloud Drive `Books/_성경` 순)을 변환해 `build/bible/embedded.cpb`를 만들고 `src/bible/generated/EmbeddedPack.S`의 `.incbin`으로 링크한다. 둘 다 gitignore다. `BIBLE_EMBED=0`이면 넣지 않는다.
- **SD 카드**: `/bible/` 폴더에 넣는다. `.cpb`가 여러 개면 이름순 첫 파일을 연다. SD 팩이 있으면 내장 팩보다 먼저 쓴다.

- 지원하는 EPUB: "ESV 템플릿" 한국어 성경(`bNN.MM.Name.text.html`, `span.chapter-num`, `span.verse-num`, `p.heading`).
- `--charset FILE`은 본문에 쓰인 글자를 모두 적는다. 글꼴 범위를 확인할 때 쓴다.
- 변환할 때 원본의 오타 몇 가지를 고친다(`FIXUPS`: 떠도는 `^`, `{}`, `ㅘㅇ하` → `왕하`).

## 구조

모든 정수는 리틀 엔디언이다. 각 구역은 4바이트 경계에 맞춘다.

### 헤더 (64바이트)

| 오프셋 | 형식 | 내용 |
|---|---|---|
| 0 | `char[8]` | `CPBIBLE\0` |
| 8 | u16 | 형식 버전 (2) |
| 10 | u16 | 책 수 (66) |
| 12 | u32 | 장 수 |
| 16 | u32 | 절 수 |
| 20 | u32 | 제목 오프셋 (UTF-8, NUL 종료, 최대 64바이트) |
| 24 | u32 | 책 표 오프셋 |
| 28 | u32 | 장 표 오프셋 |
| 32 | u32 | 절 오프셋 표 오프셋 |
| 36 | u32 | 절 플래그 표 오프셋 |
| 40 | u32 | 소제목 표 오프셋 |
| 44 | u32 | 소제목 수 |
| 48 | u32 | 압축 블록 구역 오프셋 |
| 52 | u32 | 가장 큰 장 블록의 압축 해제 크기 |
| 56 | `char[8]` | 언어 코드 (`ko`) |

### 책 표 (책마다 64바이트)

| 오프셋 | 형식 | 내용 |
|---|---|---|
| 0 | u8 | 0 = 구약, 1 = 신약 |
| 1 | u8 | 정경 번호 1..66 |
| 2 | u16 | 장 수 |
| 4 | u32 | 첫 장의 장 표 인덱스 |
| 8 | `char[40]` | 이름 (`요한복음`) |
| 48 | `char[16]` | 약어 (`요`) |

### 장 표 (장마다 24바이트)

| 오프셋 | 형식 | 내용 |
|---|---|---|
| 0 | u32 | 첫 절의 전체 절 인덱스 |
| 4 | u16 | 절 수 |
| 6 | u16 | 첫 소제목 인덱스(이 장의 첫 절 이상을 가리키는 첫 소제목) |
| 8 | u32 | 압축 블록 오프셋(블록 구역 기준) |
| 12 | u32 | 압축 블록 크기 |
| 16 | u32 | 압축을 푼 블록 크기 |
| 20 | u32 | 블록 안에서 마지막 절 본문이 끝나는 위치(그 뒤는 소제목 본문) |

장 블록을 풀면 그 장의 절 본문이 차례로 이어지고, 그 뒤에 그 장의 소제목 본문이 온다. 구분자는 없다. 블록은 64KB를 넘지 않는다.

### 절 오프셋 표

절마다 u16. 그 절 본문이 장 블록 안에서 시작하는 위치다. 끝은 같은 장의 다음 절 시작, 마지막 절이면 장 표의 `블록 안 절 본문 끝`이다.

### 절 플래그 표

절마다 u8. bit 0 = 문단이 시작하는 절, bit 1 = 시 행(`p.line`).

### 소제목 표 (12바이트)

u32 절 인덱스(소제목이 이 절 바로 위에 온다), u32 그 절이 속한 장 블록 안의 오프셋, u16 길이, u8 종류(0 소제목, 1 시편 표제, 2 시편 권 구분), u8 0. 절 인덱스 순으로 정렬한다.

### 압축 블록

장 표 순서대로 장 블록을 이어 붙인다.

## 크기

2018 개역개정 EPUB(5.9MB) → 1.95MB(버전 1의 비압축 4.8MB), 31,102절, 1,189장, 소제목 2,420개. 가장 큰 장(시편 119편)은 풀면 17KB다. 내장하면 펌웨어가 2.89MB에서 4.84MB가 된다.

## 버전을 올릴 때

헤더의 버전을 올리고 `BiblePack::FORMAT_VERSION`과 함께 바꾼다. 기기는 모르는 버전의 팩을 열지 않는다. 버전 1(비압축)은 더 읽지 않는다. 본문 검색 색인은 버전 3에서 구역을 덧붙이는 방식으로 넣는다.
