# CrossPoint Bible 계획

CrossPoint 한국어 펌웨어(`release/korean`, 1.6.5-ko.1)를 성경 전용 펌웨어로 줄인다. 성경 본문은 저장소에 넣지 않는다. 사용자가 가진 EPUB을 빌드 때 성경 팩(`.cpb`)으로 바꿔 펌웨어에 내장하거나, SD `/bible/`에 넣는다.

## 목표

- 책 → 장 → 절로 몇 번의 버튼 입력만에 이동한다. 책은 목록에서 고르고, 장과 절은 숫자로 고른다.
- 큰 글씨. 본문 글꼴 크기를 여러 단계로 내장한다.
- 쓰지 않는 기능(네트워크, OTA, OPDS, KOReader 동기화, 라이브러리, EPUB/XTC/TXT 리더, 사전, 이미지 뷰어)은 뺀다.
- UI 문자열은 I18n(`lib/I18n`)으로 유지해 나중에 다른 언어를 붙일 수 있게 한다. 책 이름은 팩에서 읽는다.

## 저작권

개역개정은 대한성서공회 저작물이다. 저장소에 개역개정 본문을 넣지 않는다(README 스크린샷의 몇 구절만). 내장 팩을 넣은 펌웨어 파일은 본문을 담고 있으므로 개인용으로만 쓰고 배포하지 않는다. 팩과 생성 파일은 빌드 때 로컬 EPUB에서 만든다(gitignore).

## 데이터: 성경 팩 `.cpb`

형식은 `docs/bible-pack-format.md`. 요점:

- 헤더 64바이트, 책 표(66 × 64B), 장 표(1,189 × 8B), 절 오프셋 표(u32), 절 플래그(문단 시작, 시 행), 소제목 표, UTF-8 본문.
- (책, 장, 절) → 본문 위치가 표 두 번 읽기로 끝난다. HTML 파싱이 기기에 없다.
- 2018 개역개정 EPUB: 31,102절, 소제목 2,420개, 4.8MB. 한글은 1,234자이고 전부 KS X 1001 안에 있다.

## 단계

1. **팩 변환기** `tools/bible/epub2cpb.py`와 형식 문서. 호스트 테스트로 표본 절을 대조한다.
2. **팩 리더** `lib/BiblePack`: 헤더 검증, 책/장/절 조회, 절 본문 읽기. 호스트 gtest.
3. **성경 화면** (`src/activities/bible/`)
   - `BibleReaderActivity`: 장 단위로 절을 이어 그린다. 절 번호, 소제목, 시편 표제를 표시한다. 좌우 버튼으로 쪽, 장 끝에서 다음 장으로 넘어간다. 마지막 위치를 저장한다.
   - `BibleNavigatorActivity`: 책(구약/신약 약어 격자) → 장 → 절(번호 격자, 한 쪽 40칸). 좌우는 한 칸, 옆 버튼은 한 줄, 옆 버튼을 길게 누르면 한 쪽. 장 화면에서 확인을 길게 누르면 1절로 바로 간다.
   - `BibleMenuActivity`: 장절 이동, 글자 크기, 줄 간격, 보기 방식, 소제목, 화면 방향, 설정.
4. **홈 대체**: 홈 화면은 없다. 부팅과 "홈"은 마지막 읽던 곳의 성경 리더다.
5. **글꼴**: KoPub Batang을 KS X 1001 한글로 줄이고 압축해 여러 크기로 내장한다(한자 제외). UI 글꼴도 한 단계 키운다.
6. **기능 제거**: 네트워크(Wi-Fi, 웹 서버, OTA, wolfSSL), OPDS, KOReader, 라이브러리, EPUB/XTC/TXT, 사전, 이미지 뷰어와 관련 lib, 테스트를 지운다. SD 펌웨어 업데이트는 남긴다(유일한 갱신 경로).
7. **이름**: CrossPoint Bible, 버전 `0.1.0`. 부팅 화면과 About.
8. **에뮬레이터 시나리오** `sim/`: 팩을 넣은 SD로 부팅 → 책 고르기 → 장/절 이동 → 쪽 넘김 → 글꼴 크기 변경을 찍어 golden과 비교한다.

## 진행 (2026-10-15)

- 1~8단계 완료. 펌웨어 2.89MB(시작 4.60MB), 첫 쪽 렌더 때 여유 힙 172KB(최대 블록 114KB).
- 팩 형식 2(장마다 deflate, 1.95MB)로 바꾸고 펌웨어에 내장했다. 내장 펌웨어 4.84MB, 이동 후 여유 힙 163KB. SD 팩이 있으면 그것을 먼저 쓴다.
- 화면 시나리오 5개(부팅, 장절 이동, 메뉴, 장 경계, 내장 팩)가 에뮬레이터에서 통과한다. 호스트 테스트 130개 통과.
- 남은 확인: X4 실기기(800×480 배치, 버튼 감, 잉크 잔상), 안티앨리어싱 켠 상태에서 강조된 절 번호 표시.
- 남겨 둔 것: SD 펌웨어 업데이트(유일한 갱신 경로), S3 보드의 USB 드라이브, 시계 설정, BMP 절전 화면.
- 설정 목록에 아직 성경 리더가 쓰지 않는 값이 있다(짧은 전원 버튼의 '쪽 넘김'·'각주', Lyra Extended 테마). 저장 위치가 순서라 빼면 다른 값이 밀린다.
- `docs/`의 옛 문서(웹 서버, 사전 등)는 아직 지우지 않았다.

- 깜빡임: 장절 이동·메뉴에서 돌아올 때 강제로 화면을 지우던 갱신(X3에서 HALF는 세 번 구동, X4에서 FULL은 여러 번 번쩍임)을 없앴다. 이제 쪽 넘김 2번(흑백+회색조), 선택 화면 이동 1번이다.
- 북마크 폴더(만들기·삭제), 북마크(추가·이동·삭제), 두벌식 한글 키보드, 양쪽 정렬(글자 단위 줄바꿈), 헤더 아래 여백, 글자 다듬기 메뉴를 넣었다. 시나리오 7개.

- 부팅·절전 화면을 검은 성경 표지로 바꿨다. 참고 사진(iStock)의 디자인을 선으로 다시 그린 것이라 사진 픽셀은 들어가지 않는다. 시나리오 8개.

- 양쪽 정렬: 단어 폭을 잉크 범위(getTextWidth)가 아니라 펜 이동 폭(getTextAdvanceX)으로 재고, 글자 간격은 그대로 둔 채 남는 폭을 띄어쓰기에만 나눈다.
- 설정 정리: 절전 화면은 어둡게/밝게/없음/빠른 재개만, 표지 맞춤·필터, 절전 이미지 선택, UI 테마, 짧은 전원 버튼을 뺐다(불러올 때 어둡게·무시·Lyra로 맞춘다). 정렬은 설정 > 리더로 옮겼다. SD 펌웨어 업데이트는 남긴다.
- 절전 화면은 표지만, 부팅 화면은 표지 + CrossPoint Bible.
- 글자 크기 14/16/18/22/28pt. 처음 기본값 18pt, 줄 간격 보통, 양쪽 정렬, 절마다 줄바꿈. 시나리오 9개.

- 공개 리포 `crosspoint-reader-ko/crosspoint-bible`. 릴리스 펌웨어는 개역한글(getBible `korean`, 공개 저작물, `data/bible/krv1961.cpb`)을 내장한다. 변환기는 getBible JSON도 읽고, 팩 제목 뒤에 메타정보(판, 저작권/이용 허락, 출처, 버전, 참고)를 싣는다. 메뉴의 성경 정보가 이를 보여 준다.
- CI(`ci.yml`): 변환기·호스트 테스트, X4/X3 빌드. 릴리스(`release.yml`): `v*` 태그에서 gh_release 빌드, 펌웨어·개역한글 팩·변환기 첨부.

- 다국어(0.2.0, `docs/languages.md`): upstream CrossPoint를 따라 기본 언어를 영어로 바꿨다. 펌웨어에는 영어 Open Translation Bible(CC BY-SA 4.0), Noto Serif 5단계, Noto Sans UI, 하이픈 패턴 11개 언어, UI 번역 24개가 들어간다(3.64MB). 나머지 23개 언어는 언어별 SD 번들(`/bible/lang/<code>/`, `/bible/fonts/<code>/`)로 릴리스에 올린다. 한국어 번들은 개역한글·열린 성경과 KoPub 바탕·리디바탕, UI 글꼴 Pretendard.
- 아랍어·페르시아어·히브리어는 기기에서 MiniBidi로 그리고, 힌디어·말라얄람어는 빌드 때 HarfBuzz로 미리 조합해 사용자 영역 글리프로 넣는다(UI는 영어).
- 책 격자: X4 칸(14pt 굵게 68px)에 맞도록 영어·독일어·네덜란드어·러시아어·이탈리아어·일본어 약어를 줄였고, 약어를 만들 때와 번들을 만들 때 폭을 잰다. 기기에서는 넘치는 약어를 자른다.
- 일본어·중국어 Noto CJK는 힌팅 정보가 없어 가는 가로획이 회색 두 줄로 흐려졌다. 번들 글꼴을 오토힌터로 그려 한 줄로 맞춘다(`fonts.lock.json`의 `hinting`).
- 양쪽 정렬 줄바꿈: 줄마다 꽉 채우던 방식(greedy)을 절·문단 전체에서 간격이 가장 고른 줄바꿈을 고르는 방식(TeX식 total fit)으로 바꿨다. 띄어쓰기가 2.5칸보다 넓어지는 줄을 왼쪽 정렬로 두던 규칙은 없앴다. X4 세로(본문 폭 438px)에서 그 규칙 때문에 18pt 줄의 17%, 28pt 줄의 42%가 오른쪽 끝에 빈칸을 남겼다. 이제 절·문단의 마지막 줄만 왼쪽 정렬이다.
- 성경 화면이 렌더 잠금(RenderLock) 없이 상태를 바꾸던 곳을 고쳤다. 렌더 작업이 이전 쪽을 그리는 중에 장 넘김·글자 크기 변경이 배치를 다시 만들거나, 성경·글꼴·언어 전환이 글꼴 객체를 바꾸면 글자가 빠지거나 깨질 수 있었다.
- 글꼴 역할: 본문과 이동(책·장·절 격자, 제목)은 본문 세리프 글꼴, 읽기 화면의 장 제목·쪽 번호와 메뉴·목록·설정은 언어별 산세리프 시스템 글꼴.
- 화면 시나리오는 빈 SD(내장 영어)가 기본이다. 언어 시나리오 9개는 `sim/make-sd.sh`로 만든 번들 SD를 쓴다. 호스트 테스트 155개.

## 뒤로 미룬 것

- 본문 검색(한글 입력기 필요). 팩에 색인을 덧붙이는 방식으로 형식 버전 2에서 한다.
- 형광펜, 여러 번역 대조. 북마크할 절을 쪽 안에서 고르기(지금은 강조된 절 또는 쪽 첫 절).
- X4(800×480) 화면 배치는 에뮬레이터가 지원하지 않아 실기기로 확인한다.
